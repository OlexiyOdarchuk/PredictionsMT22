# Передбачення від МТ-22

Це простий веб-застосунок, який показує користувачеві випадкові передбачення.

## Опис

Проєкт створено для підняття настрою та отримання дози гумору на осінньому ярмарку 2025. Передбачення охоплюють різні життєві ситуації, від навчання та ігор до програмування і повсякденних курйозів.

## Внесок

Якщо у вас є ідеї для нових передбачень, не соромтеся робити форк та надсилати пул-реквести, всі передбачення в масиві [quotes](js/quotes.js)!
